## 0. 이번 프로젝트는 무엇인가

5주차 내내 끌고 온 **관통 예제("주간 데이터 요약 리포트")** 를 토요일에 **여러분 손으로 완성**합니다.

```
[상황] 여러분은 어느 온라인몰의 마케팅/운영 담당자입니다.
       매주 월요일, 팀장에게 "지난주 데이터 요약 리포트"를 제출해야 합니다.
[핵심] 파이썬은 '숫자 요약'까지만, '해석·제안 문장'은 채팅 AI(분석가)가 만든다.
       → 5주차 규칙: API·CLI 없이, 채팅만으로.
```

> 💡 이번 주의 황금률: **"숫자는 파이썬이, 문장은 AI가, 검증은 사람이."**
> AI가 만든 문장 속 숫자는 **반드시 데이터와 대조**합니다(할루시네이션 방지).

## 1. 두 프로젝트 — 무엇이 다른가

| | **A. 난이도 하** | **B. 난이도 상** |
| --- | --- | --- |
| 제목 | AI와 함께 만드는 주간 데이터 요약 리포트 | 분석가 시스템 프롬프트 팩 + 리포트 자동화 대화 설계 |
| 목표 | "따라 하면 완성" | "설계 판단이 필요" |
| 프롬프트 | **제공된 프롬프트**를 약간 수정해 사용 | 재사용 프롬프트 팩 2~3종을 **직접 설계** |
| 데이터 | 정제된 작은 매출 데이터 | **전처리가 필요한** 주문 + 리뷰 데이터 |
| 대화 | 1~2턴으로 리포트 생성 | **멀티턴 대본**으로 리포트 완성 + 검증 로그 |
| 산출물 | 리포트 1개 | 리포트 + **재사용 프롬프트 팩** + 검증 로그 |

```
      쉬움 ────────────────────────────────────────▶ 어려움
   [A] 제공 프롬프트로 리포트 1개 완성
                        [B] 프롬프트 팩 설계 + 멀티턴 + 검증 로그까지
```

### 🧭 어느 것을 고를까 (선택 가이드)

- **A를 고르세요** — 프롬프트를 처음 진지하게 써본다 / 파이썬이 아직 낯설다 / "일단 완성"을 경험하고 싶다.
- **B를 고르세요** — 시스템 프롬프트 v2(구조화·few-shot·검증)를 자신 있게 쓴다 / 전처리·멀티턴이 궁금하다 / 팀에서 **재사용할 자산**을 만들고 싶다.
- **둘 다** — A를 2시간 안에 끝냈다면, 남은 시간에 B의 "프롬프트 팩 설계"에 도전하세요. A의 결과물이 B의 재료가 됩니다.

> 처음이면 **A**, 자신 있으면 **B**. 정답은 없습니다. **완성해서 캡처를 남기는 것**이 목표입니다.

## 2. 공통 준비물

- ChatGPT·Claude·Gemini 중 **최소 2개** 계정(무료 등급으로 충분). — "같은 프롬프트, 다른 챗" 비교용.
- **Google Colab** 접속 브라우저 (파이썬으로 데이터 요약할 때). 설치가 부담되면 Colab 하나로 충분합니다.
- 5주차에 만든 **나만의 시스템 프롬프트 라이브러리 / 리뷰 체크리스트** (있으면 재활용, 없으면 여기서 만듭니다).
- 결과를 담을 문서 하나 (구글 문서 / 노션 / 워드 등). 리포트는 여기에 붙여 완성합니다.

> ⚠️ 이번 주는 **API 키가 필요 없습니다.** 파이썬 스크립트도 **키 없이·인터넷 없이** 돌아갑니다.

## 3. 데이터 안내 (출처·라이선스)

두 프로젝트 모두 **저작권·개인정보가 안전한 공개 데이터**를 회사 데이터로 **해석**해 사용합니다.
실습 편의를 위해 `solution_data_prep.py` 가 **같은 성격의 샘플 데이터를 코드로 생성**합니다(고정 seed → 항상 같은 결과).

```
# 데이터 출처(교체용): UCI Machine Learning Repository — "Online Retail"
# URL: https://archive.ics.uci.edu/dataset/352/online+retail
# 라이선스: CC BY 4.0  (사용 전 데이터셋 페이지에서 최종 확인)
# 실무 해석: 영국 온라인 소매점의 실제 주문 내역 → '우리 온라인몰의 주간 주문/매출'
# 확인일: 2026-07-13
#
# 한국어 대안: 서울 열린데이터광장(data.seoul.go.kr) / 공공데이터포털(data.go.kr)의
#              상권·매출 CSV. 라이선스는 각 페이지에서 확인. 개인정보 데이터는 사용 금지.
```

- **왜 샘플 생성인가?** 4시간 안에 데이터 다운로드·정제로 시간을 뺏기지 않고, **프롬프트·검증**에 집중하기 위해서입니다.
- PoC 이후 실제로 쓰려면, 스크립트 상단 안내대로 `pd.read_csv(진짜_데이터)` 로 바꿔 끼우면 됩니다.
- **개인정보가 포함될 수 있는 데이터는 쓰지 않습니다.** 리뷰도 익명 합성 데이터를 사용합니다.
