# API 호출 실패

## 증상
KIS API 또는 yfinance 호출 시 인증 오류, 타임아웃, 또는 빈 응답이 반환되는 경우.

## 해결 방법

```
1. .env 파일의 API 키 확인
2. KIS API 토큰 만료 확인 (유효기간 24시간)
3. 네트워크 연결 상태 점검
```
